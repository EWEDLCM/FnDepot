# 快捷图标

把局域网服务的端口或外部链接，生成为飞牛 fnOS 桌面上的独立快捷入口。

## 功能

- 内置端口：填写端口、协议和访问路径，生成指向 NAS 内服务的快捷入口
- 外部链接：直接填写目标网址，生成任意网站或服务入口
- 每个入口可单独设置名称、图标和打开方式
- 入口部署后出现在桌面，可单独停用、编辑、卸载或删除
- 不额外占用对外端口，管理界面通过系统统一网关（Unix Socket）访问

## 使用方法

1. 打开「快捷图标」，点击「新增配置」
2. 选择「内置端口」或「外部链接」
3. 填写唯一标识、捷径名字，以及端口或目标地址，可自定义图标
4. 保存并部署后，桌面会出现对应的独立快捷入口

## 卸载说明

卸载应用时可以选择保留或删除已经部署的快捷入口。

## 环境要求

- 飞牛 fnOS 1.2.0 及以上
- x86 / arm 架构
